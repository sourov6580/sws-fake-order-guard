# SWS Fake Order Guard

WooCommerce ফেক অর্ডার প্রতিরোধ প্লাগইন — মোবাইল নম্বর যাচাই, নম্বর/IP লিমিট, ফোন নম্বর ব্লকলিস্ট, টেস্ট/এলোমেলো লেখা ব্লক, যাচাই করা অর্ডারে Facebook Purchase ইভেন্ট (Conversions API), এবং অসম্পূর্ণ অর্ডার উদ্ধার (Incomplete Orders)।
Developed by [Sabbir Web Solutions](https://sabbirwebsolutions.com)

## অসম্পূর্ণ অর্ডার / Incomplete Orders (v1.4.1)

WooCommerce → **Incomplete Orders**

- চেকআউটে কেউ সঠিক মোবাইল নম্বর লিখে অর্ডার না করে চলে গেলে নাম, নম্বর, ঠিকানা, কার্টের পণ্য ও মোট টাকা সেভ হয়। Classic, Block ও CartFlows চেকআউটে কাজ করে।
- ভুয়া প্যাটার্নের নম্বর সেভ হয় না। ব্লকলিস্টের নম্বর আলাদা "ব্লকড" ট্যাবে যায়।
- নির্দিষ্ট সময় (ডিফল্ট ৩০ মিনিট) পার না হলে তালিকায় আসে না, তাই যারা এখনো ফর্ম পূরণ করছে তারা আসে না।
- প্রতিটি row-এ কল ও WhatsApp বাটন (আগে থেকে লেখা মেসেজসহ)। ক্লিক করলে স্ট্যাটাস নিজে থেকে "কল করা হয়েছে" হয়। নোট, বাদ দেওয়া, ব্লক, মুছে ফেলা আর bulk action আছে।
- পরে একই নম্বর বা ব্রাউজার থেকে অর্ডার হলে row নিজে থেকে "উদ্ধার হয়েছে" হয় এবং অর্ডারের লিংক দেখায়, সাথে কল করার পর না নিজে থেকে।
- পুরোনো ডেটা প্রতিদিন নিজে থেকে মুছে যায় (ডিফল্ট ৩০ দিন)।

## যাচাই করা অর্ডারে Facebook Purchase (v1.4.0)

WooCommerce → Fake Order Guard → **যাচাই করা অর্ডারে Facebook Purchase** অংশে Pixel ID আর Conversions API token দিন।

- অর্ডার Completed (বা সেটিংসে বাছাই করা Processing) হলে একবার সার্ভার থেকে Meta-তে Purchase যায়। On-hold/Cancelled/Failed অর্ডারে যায় না।
- ইমেইল, ফোন, নাম, শহর (হ্যাশ করা), IP, ব্রাউজার, `_fbp`/`_fbc` কুকি পাঠানো হয়, তাই ম্যাচ কোয়ালিটি ভালো থাকে।
- PixelYourSite-এর ইভেন্ট আইডি থাকলে সেটাই ব্যবহার হয়, তাই ডুপ্লিকেট হয় না।
- অর্ডার পেজের **Order actions** থেকে হাতে Purchase আবার পাঠানো যায়। ফলাফল অর্ডার নোটে দেখা যায়।
- পিক্সেল প্লাগইনের নিজের Purchase ইভেন্ট বন্ধ রাখুন। "ব্রাউজার Purchase আটকান" অপশন যাচাই না হওয়া অর্ডারের থ্যাংক-ইউ পেজে fbq Purchase আটকায়, কিন্তু অন্য প্লাগইনের সার্ভার-সাইড ইভেন্ট আটকাতে পারে না।

## নতুন আপডেট রিলিজ করার নিয়ম

1. `sws-fake-order-guard.php` ফাইলে দুই জায়গায় ভার্সন বাড়ান: হেডারের `Version:` এবং `const VERSION`।
2. কোড GitHub-এর `main` ব্রাঞ্চে push করুন।

ব্যস। GitHub Action (`.github/workflows/release.yml`) নিজেই `sws-fake-order-guard.zip` বানিয়ে `vX.Y.Z` নামে Release পাবলিশ করবে। ভার্সন না বাড়ালে নতুন Release হবে না।

১২ ঘণ্টার মধ্যে সব সাইটে "Update now" দেখাবে। সাথে সাথে দেখতে চাইলে Plugins পেজে প্লাগইনের নিচে **Check for updates** ক্লিক করুন।
